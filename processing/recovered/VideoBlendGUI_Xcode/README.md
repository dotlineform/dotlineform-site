# VideoBlendGUI (SwiftUI + FFmpeg)

A macOS SwiftUI app that blends two videos with opacity control,
optionally reverses one, adjusts enhancements, and can do slow-motion
frame interpolation.

## Build Instructions
1. Open Xcode
2. Create a new SwiftUI App project named `VideoBlendGUI`
3. Replace `VideoBlendGUIApp.swift` and `ContentView.swift` with the files in this folder
4. Build & Run

Open data/mo_table.csv in any spreadsheet app or a text editor. Each row maps a dice sum (2–12) to three fields:

  1. outcome — a short label (e.g., “Very favorable”).
  2. advice — the high-level guidance.
  3. remedy_note — optional: practices, offerings, or rituals.

Save, then re-run the app (or press SPACE) to reload and display your lineage guidance on-screen.

Citations: For cultural background on Tibetan mo, see Encyclopaedia Britannica (Divination), StudyBuddhism overviews. For QRNG background, see ANU API docs and NIST beacons. Links are in the project README.

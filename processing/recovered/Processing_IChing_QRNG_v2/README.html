Exported: 2025-09-25 14:44:51 BST

What’s new in v2

  • Tibetan mo mode — press M to toggle between I Ching and mo. QRNG generates two independent 1–6 samples to preserve the natural 2–12 bell curve.
  • Logging — press L to toggle logging. When on, each cast is saved to data/log.csv (timestamp, mode, question, hexagram/mo result, changing lines, source).
  • Question prompt — press Q to enter an optional question; it’s stamped into the next logged record.

Controls

SPACE new cast • R auto-refresh • S screenshot • M I Ching/mo • L logging • Q set question

QRNG mapping (I Ching): uses 3 bits per line (000→6, 111→9, one‑hot→7, two‑hot→8) to match the 3‑coin probabilities (1/8, 3/8, 3/8, 1/8).

QRNG mapping (mo): samples two independent 1–6 values; sum → 2–12 with natural dice probabilities. Manual lookup is up to your chosen lineage table.

Online/offline: If the ANU QRNG API is unreachable, the app falls back to PRNG and marks the source in the UI and log.

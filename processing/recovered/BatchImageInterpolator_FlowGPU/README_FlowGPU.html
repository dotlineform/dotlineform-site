Batch Image Interpolator — GPU Flow Warper

Prepared — 2025-09-02 15:57:37 (Europe/London)
Computes/caches optical flow (CPU), packs to RG flow texture, warps on GPU (GLSL) per frame.
  1. Place ordered images in input/.
  2. Adjust QUICK CONFIG in BatchImageInterpolator_FlowGPU.pde.
  3. Run. Frames in out/; flows cached in out/flows/.

Why GPU?

  • CPU computes flow once per pair; GPU does all per-frame warps and blending.
  • Flow packed into an 8-bit RG texture; decoded in shader with a per-pair scale.
  • Gamma-correct + premultiplied alpha blending in the shader.

FFmpeg

ffmpeg -r 25 -i out/frame%06d.png -c:v libx264 -crf 18 -preset medium -pix_fmt yuv420p slow_morph_gpu_25fps.mp4

Notes

  • We disable mipmaps for the flow texture to avoid sampling artifacts.
  • The flow scale is computed per pair (max |u| or |v| in pixels) and passed as a uniform.
  • If you want higher precision flow textures, switch to OpenGL float textures; this 8-bit RG pack is usually sufficient.

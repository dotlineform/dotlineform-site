Batch Image Interpolator — Optical Flow (Horn–Schunck) with Per‑Pair Cache

Prepared — 2025-09-02 15:50:52 (Europe/London)
Drop-in replacement for crossfade: computes & caches flow per pair, then morphs frames offline.
  1. Put ordered images in input/.
  2. Adjust QUICK CONFIG in the PDE (canvas size, INTER_FRAMES, HOLDs, FIT_MODE).
  3. Run the sketch. Outputs appear in out/; flow caches in out/flows/.
  4. Re-runs will reuse cached flow unless you delete it.

FFmpeg stitching

ffmpeg -r 25 -i out/frame%06d.png -c:v libx264 -crf 18 -preset medium -pix_fmt yuv420p slow_morph_25fps.mp4

Notes

  • Flow is computed on the canvas-sized, prepared images (after FIT/FILL/STRETCH). This guarantees coordinate consistency.
  • For UHD, consider increasing LEVELS and reducing HS_ITERS per level.
  • Set SHOW_PREVIEW=false in very large runs.

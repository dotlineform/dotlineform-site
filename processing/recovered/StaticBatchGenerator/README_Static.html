Static Batch Generator — No draw(), all work in setup()

Prepared — 2025-09-02 17:43:52 (Europe/London)
MODE = CROSSFADE | FLOW_CPU | FLOW_GPU. Processes all pairs, writes frames, then exit().

Use

  1. Create input/ and drop ordered images.
  2. Open StaticBatchGenerator.pde; set MODE, sizes, and parameters.
  3. Run: all frames saved to out/, flows to out/flows/ when applicable.

Why this pattern

Avoids reliance on draw() or frameRate; suitable for long, resumable rendering runs. You can launch, wait for completion, and get a deterministic set of PNGs.

FFmpeg

ffmpeg -r 25 -i out/frame%06d.png -c:v libx264 -crf 18 -preset medium -pix_fmt yuv420p static_batch_25fps.mp4

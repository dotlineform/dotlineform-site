# VideoBlendGUI (macOS, SwiftUI + FFmpeg)

A macOS SwiftUI app that blends two videos with adjustable opacity, optional reverse on the second video, scaling/padding to match sizes, auto-levels/histogram equalization/EQ post-step, and optional audio mix. It uses FFmpeg/FFprobe.

## Prerequisites
Install FFmpeg:
```bash
brew install ffmpeg
```

## Build
1. Open **Xcode** → New Project → App (SwiftUI).
2. Replace files in the project with those in `Sources/`.
3. Build & run.

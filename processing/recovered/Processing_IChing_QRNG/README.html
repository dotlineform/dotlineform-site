I Ching × QRNG — Processing App

Exported: 2025-09-25 14:37:28 BST

What this is

A Processing (Java mode) app that casts the I Ching using a real‑time quantum random number generator (QRNG) from ANU. It maps QRNG bits to the 3‑coin probabilities (old yin/yang = 1/8; young yin/yang = 3/8) and produces a primary hexagram and an optional resulting hexagram (from changing lines). It includes short hexagram names; bring your own translation for judgments/lines.

How to run

  1. Install Processing (Java mode).
  2. Open the folder Processing_IChing_QRNG in Processing (open the .pde file).
  3. Run. Press SPACE for a new cast. Press R to toggle auto‑refresh (default 10s). Press S to save a PNG.

Online vs offline: If the QRNG API call fails, the app gracefully falls back to a local PRNG (not quantum). The status line at the top shows which source was used.

Mapping logic: Three QRNG bits per line → 000 = 6 (old yin, changing), 111 = 9 (old yang, changing), one‑hot = 7 (young yang), two‑hot = 8 (young yin). This reproduces the 3‑coin distribution.

Indexing: Bottom line is line 1 (LSB). The primary hexagram index is 0‑63 where yang=1, yin=0. Changing lines flip in the resulting hexagram.

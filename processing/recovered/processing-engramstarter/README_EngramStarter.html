Engram Starter — Processing

This starter kit scaffolds a deterministic, batch‑oriented Processing workflow aligned to Substrate · Emergence · Experience. It includes PDE classes, a main sketch, and CSV/JSON manifest templates.

Structure

  • EngramStarter/EngramStarter.pde — main entry (static render, noLoop default)
  • EngramStarter/Substrate.pde
  • EngramStarter/Emergence.pde
  • EngramStarter/Experience.pde
  • EngramStarter/Params.pde
  • EngramStarter/data/manifest_rules.csv, manifest_rules.json

Notes

  1. Static renderer: uses noLoop() so draw() runs once. Use loop() to iterate or export multiple frames.
  2. Use settings() when size is parameterized. The starter uses size(1920,1080,P2D) by default.
  3. CSV manifests follow common conventions; JSON manifests are read via Processing’s JSON API.

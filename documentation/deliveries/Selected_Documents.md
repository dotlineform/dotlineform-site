# Selected Documents

The Star workflow made selection an independent Working source control. A shared report could use saved membership and exact document targets without storing stars in front matter or tying them to Search and Recent. The user chose to load the list when the report opens. The delivery also kept source timestamps out of Star writes and sorted report rows by document update day.

The user accepted the initial workflow on 26 September 2026 after using it. The original source review and static validation covered target routing, persistence and output projection. Individual Delete and Publish scenarios were outside that acceptance report.

The October 2026 report update verified real Working and public rows through the shared ordering and route-preparation code. That check covered the saved list and exact URL construction. The review also traced one policy read per view, known-row updates and disposal. Browser interaction and transfer remained separate checks.

[Selected Documents reference](../reference/Source_Organisation.md#selected-documents) describes the current report host, payload and queue. The delivery used the former Preview workflow.

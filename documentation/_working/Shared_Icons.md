# Shared Icons

## Remaining Outcome

Use the saved [canonical SVG collection](../../docs-viewer/static/icons/) consistently in remaining web surfaces and, if separately adopted, native Mac/iPad views. Current [interface icon behaviour](../reference/Toolbar_Icons.md), [manual tokens](../reference/Icon_Tokens.md) and [configured collection markers](../reference/Source_Organisation.md#collection-icons) are implemented. Generated [Related Links](../reference/Related_Links.md) now uses destination icons; that former follow-on is complete.

The [design record](../design/Shared_Controls_And_Visual_Assets.md) keeps family, drawing and ownership rationale. [Delivery evidence](../deliveries/Shared_Controls_And_Visual_Assets_Review.md) records the accepted Studio conversion and the limits of earlier verification. This proposal is not a runtime asset registry.

## Open Decisions

- [ ] Finish the recorded [toolbar visual review](Toolbar_Icon_Mapping.md), [manual icon acceptance](Icon_Tokens_Delivery.md) and [collection marker acceptance](Collection_Icons_Delivery.md). Source inspection does not supply user acceptance.
- [ ] Choose any additional report/Index artwork and whether a destination needs collection, Subject or another type cue. Preserve text sorting and identity independently of prefixes. The diagnostic Links report's title cells remain their own extension point.
- [ ] Establish the canonical artwork origin/version/notice record and how required notices travel with projected or packaged artwork. The current tracker records the missing adjacent provenance record as a file follow-up.
- [ ] Decide whether native App reuse is wanted, then select a bounded native-owned integration with its own acceptance. Candidate outputs are bundled web resources and prepared native image assets from the same artwork; neither implies a generic runtime SVG loader or browser CSS applying to SwiftUI.

Keep ordinary emoji in authored prose. Additional interface artwork requires an explicit selected consumer, action meaning, renderer and public/local serving owner. A proposed combined image modal is separate workflow work and has no approved implementation in this icon batch.

# Shared Controls And Visual Assets

## Keep The Decision With Its Caller

A reusable interaction can own transient highlighted rows, picker navigation and accessible event wiring without knowing the operation that follows. App adapters already have the domain records and draft; keeping normalization, committed values and workflow decisions there avoids turning every field or list into a server feature. Injected loaders expose required filesystem work while the server retains its actual confinement/persistence boundary. [Current components](../reference/Shared_UI.md)

Shared placement is evidence of the same responsibility, not a reward for a generic-looking API. Two real consumers normally establish it. The reviewed Folder Picker exception represents Projects-tree navigation independent of one shell, despite its one adopter. File Picker's bounded folder/subfolder plus file-membership output serves a different task; neither needs to become the other's base class.

## Placement Is Separate From Operation Authority

The object the user is acting on chooses the surface; frequency and discoverability choose whether a control is direct or secondary. An invoked Index row can differ from the displayed document, while a collection's checked IDs belong to its mounted report. Moving an action into Edit or Actions must preserve that target and its workflow owner.

Code-owned definitions, stable mounts and focused state projections allow Public, Manage and Review to share presentation without importing each other's local authority. Home/theme composition and report-local controls need not become registry definitions merely because they look like toolbar buttons. [Current surfaces](../reference/Panel_Hosts_And_Control_Surfaces.md)

## One Drawing, Different Adapters

Saved SVG geometry is independent of control identity, button hit area and theme. Web masks keep outline geometry and tint it through text colour; genuinely coloured drawings use image presentation. The selected outline-family starting point is a 24-unit canvas, 2-unit rounded strokes and clear optical margins/gaps. Preserve approved Catalogue/brand geometry instead of redrawing it solely to match a viewBox. Review small-size fit manually.

Lucide supplied general action artwork; custom Work/Series/Detail and the traced home mark retain their chosen geometry. A missing proposed spanner drawing was resolved by choosing existing wrench artwork. The accepted Studio conversion retained identifying Gallery text and text labels for confirmation, destructive confirmation, entry Save/Cancel and picker controls. Artwork changes did not change Save/publication behaviour.

Manual document tokens name exact extensionless files instead of creating a second meaning registry. Build-time embedded sanitized masks make prepared HTML portable through Review/Export/Publish, at the cost of repeated markup and an explicit document rebuild to capture changed artwork. Interface masks instead fetch the explicitly served SVG. [Current icon owners](../reference/Toolbar_Icons.md)

## Explicit Public Output

The installed public shell, runtime projection and document publication are separate owners. One canonical runtime and an explicit tracked public subset keep local styles/pickers out of public imports while supporting a static deploy root. An installed shell remains independent of its reusable template. [Current shell and projection](../reference/Public_Docs_Route_Shell.md)

Native packaging and further icon choices remain [proposals](../_working/Shared_Icons.md). Historical static checks and pending visual acceptance are [recorded separately](../deliveries/Shared_Controls_And_Visual_Assets_Review.md).

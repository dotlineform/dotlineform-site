# App Home

## Purpose

This is the durable documentation index for the native dotlineform application. It records the application as it exists now and routes each lasting responsibility to one current owner outside the [Roadmap](/docs/?scope=app&doc=d-20260902-143007-05a794) feature hierarchy.

The application is one Swift 6 target for native Mac and iPad only. It lives beneath `app/` in the `dotlineform-site` repository but remains separate from the website runtime, tracked `site/` artifact, Docs Viewer content lifecycle, and Processing project.

The native application reuses the canonical Docs Viewer HTML, CSS, and JavaScript in `WKWebView`; it does not create a second viewer. Swift owns the native host and authorised local access, while the existing viewer continues to own document presentation and browser interaction.

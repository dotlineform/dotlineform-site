# v0.3 - Scope selection

The user selects a Published scope folder, the App retains authorised access, validates it, and provides offline tree, document, Search, recent-document, and media reading.

- Scope selection
- retained permission
- security-scoped access
- local failure presentation
- Until v0.3 exists, Swift owns no external scope selection or retained access.

# Sub-scope Documents And Media Structure

## Requirements

Each collection owns its documents and media. Place `sub-scopes/` beside `documents/` and `media/`, with each child repeating that structure. Apply the same collection boundary to Source, Generated and Published. Analysis retains separate Working and Pre-publish inputs and one accepted `published/` snapshot.

Document image/file insertion copies into the exact collection's media folder; an existing filename uses the ordinary replace decision. There is no shared-image registry. Catalogue images remain links to Studio-owned output under `catalogue/...`. Existing explicit external image links, including the restored Moments images, retain their destinations.

This is the local structure delivery. Do not enable Analysis promotion actions, publish new content or change deployment destinations. Confirm the later `published/` to `site/`/R2 behaviour separately.

## Deliverables

- Consistent configured paths and collection-owned media resolution, builds, accepted snapshot reads and lifecycle operations.
- Existing local content migrated with document identities, media bytes and collection boundaries verified; no retired-path fallback.
- Exact scope/stage/sub-scope targeting for image/file insertion, preserving replace confirmation.
- Updated Source Organisation and focused verification. Keep the completed Moments changes intact.

```text
<scope>/<stage>/source/        stage omitted for unstaged scopes
  documents/
  media/{img,svg,files,html,build-source/mermaid}/
  sub-scopes/<collection>/
    documents/
    media/{img,svg,files,html,build-source/mermaid}/

<scope>/<stage>/generated/
  documents/
  media/
  sub-scopes/<collection>/{documents,media,search}/

<scope>/published/
  documents/
  media/
  sub-scopes/<collection>/{documents,media,search}/
```

## Process

Select the document's collection, insert a local image or file, resolve any filename replacement, then save the document. Build prepares that collection's generated documents and media. Publish accepts documents and media into `published/`; deployment consumes that accepted snapshot through a separate delivery. This delivery did not enable Analysis promotion controls.

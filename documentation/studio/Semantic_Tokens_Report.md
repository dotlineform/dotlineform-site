# Semantic Tokens

The Semantic Tokens report and its host document `d-20260912-110653-264748` are retired. Build no longer produces a semantic usage index, and its read endpoint and report registration are removed.

Work image and Work Media View text tokens now contribute ordinary document relationships to Catalogue subdocuments. [Related Links](Related_Links.md) presents those relationships for portfolio exploration; Gallery Media View links continue to open Media View without creating a document relationship. [Semantic Tokens Architecture](Semantic_Tokens_Architecture.md) owns token parsing and rendering. Link validity remains an authoring concern, with [Docs Broken Links](Broken_Links.md) providing the separate audit.

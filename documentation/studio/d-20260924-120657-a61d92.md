# Shared Icons: Studio Works Editor Mapping

This table records the approved Studio Works editor conversion. It belongs to [Shared Icons](d-20260910-223116-9a1011.md); the existing [Docs Viewer Toolbar Mapping](d-20260919-100234-038395.md) remains separate. The previous-artwork column retains the migration baseline, including the separate Gallery/Series New and Edit flows. Series remains a search field without chips.

## Scope And Decisions

The table includes Works editor action buttons, its modal buttons and the two resource-row type icons. Modal selectors are scoped to the named modal; matching roles in another modal are distinct controls. Search-result rows, list selection, ordinary text links, form fields, thumbnails and the global Studio shell are outside this artwork inventory. The image picker uses single selection, so its hidden shared select-all/deselect-all controls are not Works editor actions.

The user approved all recommendations and accepted the visual result on 24 September 2026. SVG rows are adopted; `Keep` rows retain their existing text. All selected SVG files remain under `docs-viewer/static/icons/`; no downloads, new drawings or asset copies were required.

The table is a human-edited selection record, not runtime configuration. An artwork change preserves the existing action, accessible name, tooltip, keyboard interaction, selection rules and disabled/busy state. The same button appears twice where its current artwork changes with state.

## Implementation

The artwork remains in `docs-viewer/static/icons/`. The existing Studio HTTP server permits SVG requests beneath that directory through its normal repository static-file handler. `studio.css` supplies CSS masks and `currentColor`, adapted to Studio's theme variables: 20px artwork inside 32px icon buttons, transparent/borderless resting state, enabled hover background, visible keyboard focus and disabled tint. Gallery removal uses 12px artwork within the existing pill control; resource type cues use 16px. Full Docs Viewer stylesheets and runtime JavaScript are not loaded.

`studio-icon.js` creates decorative spans for generated controls; route markup supplies the same classes for static buttons. The layout renderer switches chevron classes without replacing the control. The shared [Record List And Actions](d-20260614-201632-79c9cb.md) renderer accepts optional caller-owned icon classes for resource actions and type cells. Icon actions require an accessible name; resource type values supply the File/Link accessible labels. Other record-list consumers retain their existing rendering.

This conversion implements only the approved artwork rows. It does not relocate assets, create independently maintained SVG copies, redesign other Studio routes, restore Series chips, mutate Catalogue data or change Save/Publish behavior. The existing SVG files and Docs Viewer runtime are unchanged, so no public asset projection is needed.

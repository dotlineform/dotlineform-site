# Moment IDs And Subjects

## Outcome

Each Moment is an original work represented by its own document. Add quoted `moment_id` values `001`–`056` in the current builder's case-insensitive title order, with numeric titles first. This is initial allocation only: later title changes and additions do not renumber existing Moments. Preserve all document IDs, titles, dates, bodies and media.

The document owns Moment identity. `moment_id: "001"` projects to subject kind `moment`, key `001`, alongside Work, Series, Detail and Folder. Moment and Series `001` are distinct identities. Moments remains its own Analysis Working sub-scope and reuses the existing Working subject controls; no Catalogue record or separate Moment registry is created.

## Boundary

Extend subject parsing, validation, source formatting, metadata assignment/import and private association projection. Display Moment subjects and allow their IDs to be edited through the existing Subject control. Reject duplicate Moment IDs within a built collection; absent IDs remain allowed. Semantic tokens, cross-document destination selection, promotion, Publish, Deploy and automatic allocation for future Moments remain later work.

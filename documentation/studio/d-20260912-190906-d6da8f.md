## Requirements

An author can use **Add Media View link** to insert a text link to an exact Catalogue Work, Detail or Series. Activation opens the selected image or Series gallery inside Media View. Catalogue owns identity, membership, ordering, metadata and media; a corresponding document or Subject is never required.

| action | available targets | authored document content | Media View entry |
| --- | --- | --- | --- |
| Add Catalogue image | Work primary image or exact Detail | Image and optional caption/presentation | Selected Work or Detail image |
| Add Media View link | Work, Detail or Series | Editable text link | Selected Work image, Detail image or Series gallery |

Add Catalogue image remains Work/Detail-only. Document content gains no galleries or Series-image tokens. A Series has no stored primary Work or image; any Series thumbnail derives from its first ordered member, with none for an empty Series.

The link modal shares the image modal's Catalogue picker design. Search finds typed Work/Series title or identity matches. A Work offers primary/Detail selection; a Series identifies its gallery directly. Selected or authored text is preserved, untouched defaults follow the chosen title, and inserted labels remain literal text.

A Series gallery displays 48 Works per page, up to eight columns and six rows of 64px thumbnails with 8px gaps, using existing 96px files. The grid is centred beside the right information column. Compact position/total and arrow-only controls are left aligned; visible thumbnail titles and the additional Work-range caption are omitted. Page and Work navigation cycle in both directions. Single-page and single-Work arrows are disabled, and empty galleries have no pagination.

Work traversal follows the complete supplied Series order. Successful selection determines the gallery return page; failed or superseded reads preserve the current selection/page. Direct Work or Detail entry invents no sequence. Back to document preserves the exact invoking document, stage and child context through Content Detail.

Use existing generated Catalogue records through local/public providers. Read one compact Series membership record and only selected Work records, render the active gallery page, and preserve visible retryable failures. Do not embed complete Catalogue records in newly authored tokens, preload every full image or introduce competing cache/history policy.

## Process

1. Select optional text in Working Markdown Source and open Add Media View link.
2. Search Catalogue and choose a Work primary, exact Detail or Series; review the editable label and insert.
3. Save through ordinary Document Build. The result retains authored text and exact identity.
4. Open the link, browse the gallery and Works, and return to the gallery without leaving Media View.
5. Use Back to document to restore the invoking content. Existing Catalogue images retain their presentation and activation behavior.

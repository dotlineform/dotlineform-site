# Semantic Tokens

The [Semantic Tokens report](/docs/?scope=analysis&stage=working&doc=d-20260912-110653-264748) is available only in Analysis Working. It reads the shared generated occurrence index covering the main collection and every configured sub-scope.

The three sortable columns are Title, Identity and Document. Each document link retains its exact collection, report host and Working stage. Repeated occurrences appear separately. Publication flags, draft state and Subjects do not filter usage.

Save and Build update the inventory before completing. Reopen the report to read current data. Work media references retain their authored identity for runtime resolution; unresolved token diagnosis remains with [Docs Broken Links](/docs/?scope=studio&doc=d-20260423-165116-e7f7e9).

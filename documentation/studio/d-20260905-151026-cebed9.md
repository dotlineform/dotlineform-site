# UAC 3B - Works In A Series Report

## Requirements

Implement the next bounded [UAC 3](/docs/?scope=studio&doc=d-20260904-204816-0f31be) branch: a real `analysis.works` sub-document lists the Works in its declared Series. Use the current report mechanics as simply as possible, then review what should carry forward into production [Gallery List Design](/docs/?scope=studio&doc=d-20260905-141447-f72ef3).

## Deliverables

- A Manage report for the exact document's Series subject, reading prepared `catalogue/generated/series/index/` JSON through the local read service.
- Work number, title and year rows, a text filter and Refresh, in a bounded table. Work titles open image and metadata in Media View; document and file actions remain part of the subsequent list design.
- Shared child report-host wiring, including report metadata in child payloads, preservation of Markdown formatting after the inserted host, and protection against late loads from an earlier child. Nested sub-scope collections are not part of this slice.
- An Analysis Works example for Series `143`, containing Works `01941` and `01942`, plus a source-editor directive insertion action.

The new report reads generated data in Manage. Production publication of dynamic Catalogue data remains governed by [Publish workflow](/docs/?scope=studio&doc=d-20260905-141447-c33de1); this delivery does not implement that pipeline or change subject assignment.

## Process

Open [Series 143 - Works](/docs/?scope=analysis&stage=working&doc=d-20260801-073826-8865a8&subdoc=d-20260906-164540-4f0e39) through the Analysis Works collection. The report derives the Series from `series_id` in that document, loads current generated member rows, and filters within that Series. Refresh rereads generated data. Navigate between the child and collection normally. Source → Directives → Works in this Series inserts the report declaration without a duplicated Series ID.

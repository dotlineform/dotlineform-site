# Document-owned Concept And Moment IDs

## Requirements

Final user review on 2026-09-08 changed the outcome. A document discusses concepts or presents a moment; it does not need to define a separate entity. Its existing `doc_id` identifies the document and its collection supplies classification. Remove the additional `concept_id` and `moment_id` model before closing this delivery.

Subject remains an association to a Catalogue Work, Series or Detail, or a Folder. Keep the completed removal of Moment from Subject. The user also retired Concept group classification: remove `group` metadata rather than carrying it into the document model.

## Deliverables

- Remove `concept_id`, `moment_id` and `group` from affected canonical source documents, including retained Working and Pre-publish source where present, and retire their allocation, validation and generated identity/association machinery.
- Remove Concept group settings, selector, filters, metadata/import/transfer handling and projected group information. Concepts and Moments no longer need their specialised collection customisations.
- Remove Concept/Moment ID allocation and display controls, dependent capabilities and requests, and any remaining identity-only modal wiring. Retire the Concept entity token action and its Add/Info modals with the dependent token machinery.
- Before deleting IDs, resolve existing Concept tokens to their exact document targets and migrate them to ordinary document links with the same labels and destinations. Do not leave broken references or retain an ID alias/lookup as a second identity system.
- Preserve `doc_id`, titles, headings, non-reference body content, poetry, media and unrelated metadata. Update affected generated output and remove tests that only protect the retired model.
- Reconcile Source Organisation and Doc Relationships with the implemented cleanup. Scope-wide membership metadata belongs to [Document Sub-scope Metadata](/docs/?scope=studio&doc=d-20260908-184516-f87fc8).

Accepted Published output and the live release remain unchanged. Publish, Deploy, promotion, a new document-link token and authored relationship persistence are separate work. Computer control remains excluded from this cleanup.

## Process

Authors continue to create and edit documents in their existing collections without allocating Concept or Moment IDs. Existing references continue to open the same documents. The follow-on delivery supplies automatic `sub-scope` front matter; this cleanup does not add replacement identity controls.

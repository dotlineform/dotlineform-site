# Catalogue Architecture

## Current Shape

Studio owns canonical Catalogue editing and complete generated output:

```text
canonical Works, Series and per-Work Details
  -> validated Studio mutation
  -> required media completion
  -> external generated Catalogue JSON, indexes and thumbnails
  -> private Studio lookup refresh
```

[Catalogue Source Model](/docs/?scope=studio&doc=d-20260519-000000-a0da45) owns identities and canonical relationships. [Catalogue Build And Lookup Refresh](/docs/?scope=studio&doc=d-20260519-202931-0c703e) owns Save and maintenance operations. [Catalogue Indexes And Payloads](/docs/?scope=studio&doc=d-20260519-202931-b05d27) describes the external consumer data.

Works have optional singular Series membership. Empty Series and ungrouped Works are valid. Detail sections and records belong to one per-Work aggregate. Catalogue records have no publication state, primary-Work prerequisite or parallel Markdown prose.

## Separate Authorities

Canonical source is optimized for understandable validated edits. Private Studio lookups support local search and editing. External `catalogue/generated/` contains complete Work/Series records, compact indexes and thumbnails for consumer use; it is replaceable output.

Save completes affected output after persisting the canonical transaction. Failures preserve that saved state and report the incomplete step. Full JSON maintenance reuses current media references and reports missing thumbnails without processing primary media.

Docs public acceptance remains separate. The full generated Catalogue is available, but the coordinated local Docs provider switch and accepted Analysis Catalogue-dependency projection are still unimplemented. The legacy site, Search, Recent and media under the archive remain frozen outside active writes.

## Change Method And Weak Spots

Change canonical fields through the source definition, serializer, editor and affected projections together. The field registry is an inventory, not a second generation planner. Use focused service/generator evidence for the changed data or ownership boundary.

Some validation and focused generation still load the full corpus. Save may prepare all Details of an affected Work, and large-collection latency has not been measured. Studio also combines generated lists with service-only focused reads; keep those distinct from the external consumer output.

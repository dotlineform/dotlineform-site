# Sub-Scopes

A sub-scope is a collection of normal Docs Viewer documents saved in a sub-folder of the main scope. These docs do not appear in the Index panel, instead they are listed in a Docs Viewer report page.

The benefit of a sub-scope collection is that hundreds of documents can be contained in a single sub-scope without overloading the main document Index-tree. 

`dotlineform/projects` and `dotlineform/processing` are Working collections. Both use exact Folder, Work or Series subjects, but Processing begins empty and separately lists only the direct project folders beneath the configured external `processing/` work-media root. Its report guidance is: **When ready for publishing, copy to `analysis/works`.** The main `processing` scope remains the ordinary home for technical documentation.

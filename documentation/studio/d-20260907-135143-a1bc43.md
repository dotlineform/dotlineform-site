# Retire Studio Tags And Adopt Concept IDs

## Requirements

The user approved retirement and rename on 7 September 2026. Studio Tag registry, aliases, assignments, groups and their editing machinery have no retained authoring role; Concept documents already contain the required definitions. Rename the active Concept domain to `concept_id`, preserving document identities, identifier values, occurrence titles and document destinations. The complete token domain now uses `concept:concept`, including module names, parser functions, registration, controls, lookup records and generated usage. Authored tokens are migrated; no old-syntax alias is retained.

This implements the ownership/naming portion of [Doc Relationships](/docs/?scope=studio&doc=d-20260907-125101-d3bde6). Relationship storage, modal design, Work/Series uniqueness and quiet reassociation, Publish rules and public token destination binding remain separate work. Published snapshots and the frozen archive are outside the migration.

## Deliverables And Process

- Remove Studio Tag routes, UI, services, canonical/config data and dedicated checks; Catalogue editing remains available.
- Rename Concepts metadata, imports, projections, management fields and source declarations in Working and Pre-publish, with no legacy-field alias.
- Resolve Concept tokens through exact Concept documents; remove registry, alias and preferred-document selection dependencies.
- Rebuild affected generated collections and the semantic lookup, project changed shared runtime code, and update durable documentation.

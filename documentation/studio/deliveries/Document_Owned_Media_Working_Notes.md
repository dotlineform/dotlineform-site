## Decisions And Scoped Review

The browser owns draft/pending-file membership, explicit Edit intent, independent thumbnail choice, local token serialization, dirty/discard state and report presentation. Python owns the exact existing Save target, canonical destination construction, upload/format/sanitizer boundaries, selected persistence, exact generation and transfers. New-selection identity preparation resolves configured capability without a source read, File upload, conversion, storage comparison or permanent write.

Save prepares selected outputs before permanent writes; it does not introduce a separate author confirmation/preflight workflow. Matching stored bytes are reused, explicit Edit permits replacement, and unexpected new/competing files fail for author correction. Sanitizer changes are returned as nonblocking media_notes. The response's media_effects distinguishes attempted, written, verified and unchanged outputs. media_complete/source_saved/generation_complete describe this request's actual outcomes; they are not persistent progress/resume flags. Committed metadata is exposed only after source persistence. Before that point, failures retain draft/Files; after media/source completion, the persisted buffer becomes clean and pending Files are released even if generation/handoff later fails. Fresh display remains in the same awaited busy lifetime.

DOM.1 review removed basename destination defaults/fallbacks, repeated import owner loads and duplicate HTML destination preflights. DOM.2 separately reviewed normal/plain/unchanged Save, selected membership, replacement, thumbnail-only/latest-choice behavior, discard, oversize requests and media/source/generation/display failure ordering. It removed immediate intake writes, Replace/sanitizer confirmation/resubmission, duplicate raster validation and SVG sanitization, unused opaque/SVG temporary byte copies, the corpus media-requeue scan, downstream multipart-envelope audits and the missing-upload fallback. It reused known file identities, prepared bytes, stat sizes and sanitizer diagnostics. Source extraction/publication retain the shared fixed-thumbnail helper.

Retained safeguards have concrete owners: HTTP MIME/size/field parsing prevents malformed or oversized native requests; exact target/configuration and confined adapters select authorised local paths and reject traversal/symlink escape; format/static-image/sanitizer/producer checks establish valid selected outputs; selected collision checks enforce author replacement intent; selected write/byte verification establishes completed effects. There is no sharing audit, media-directory/remote inventory, fallback root, compatibility alias, persistent staging/cache/queue, automatic filename allocation, split coordinator, rollback or retry machinery. Partial writes can leave manual cleanup orphans. DOM.4 still owns distinct final review after removal effects are implemented.

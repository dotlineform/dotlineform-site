## Outcome And Ownership

Manage documents containing Catalogue Image or Entry references await their existing presentation requests, mount width/height markup, then reveal the document. Distinct Works resolve in parallel through one operation's existing read reuse. Initial display, Source Save redisplay and retained/Back activation use the same awaited readiness boundary. No timer, polling, image-download wait, token dimension copy, schema change or generation-time Work read is added. Public keeps prepared markup; documents without inline Catalogue images retain ordinary display.

The Catalogue mounter returns explicit `ready` and `release` handles. The media adapter registers disposal immediately and reports whether the completed mount is still current. Document rendering/activation owns visibility; navigation awaits restoration before capture, scroll and focus. Work lookup failures settle into the existing per-reference error/Retry UI and release the display boundary. Released or superseded mounts cannot reveal another document. Text-only Catalogue links render their authored labels and resolve Work presentation on activation, avoiding an unused eager read.

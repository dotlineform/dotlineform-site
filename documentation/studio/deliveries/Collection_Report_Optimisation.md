The browser owns list preparation, rendering, selection and retained lifetime. Python Build/Import continue to own valid saved manifests and committed records; no server, source, manifest schema, generated data, publication or workflow change is included.

Use the existing browsing-data module for shared presentation preparation and cached ordering. Public consumes a read-only inventory without edit indexes, selection-ID arrays, reload revisions, saved-document subscriptions or collection-refresh callbacks. A Manage-only list controller reuses the shared presentation, owns mutable inventory and complete/filtered IDs, applies known committed records to one row and invalidates only affected ordering/filtering. The local Source adapter owns document-change events and Save projection; the provider forwards that capability only locally. Load media policy once only when a Work-thumbnail choice actually needs it. Carry the resolved collection and prepared inputs without compatibility aliases, repeated lookup/copying/deduplication or saved-domain audits. Register disposal before asynchronous composition/loading; retain controller-owned subscription cleanup and the separate tab snapshot's restoration responsibility.

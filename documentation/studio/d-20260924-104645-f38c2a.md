# Gallery And Series Definition Editing

## Requirements

- Give Galleries a New button beside the field. Clicking a Gallery pill's title opens Edit; its × continues to change only the Work draft's membership.
- Keep the Series search field without chips, with separate New and Edit buttons. The Series browser also separates New from Edit.
- New modals contain OK and Cancel. Edit modals contain OK, Cancel and Delete; neither Edit modal contains New.
- OK saves the shared definition immediately. Creating a definition selects it in the Work draft where that assignment is editable; ordinary Work Save persists the assignment. Cancelling New creates nothing; discarding the Work draft after OK leaves the saved definition available.
- Gallery Delete confirms the complete saved member count, removes the definition and all memberships together, and completes affected output without a later Work Save or manual Build. Series Delete remains disabled for a non-empty Series and is revalidated by the service.
- Preserve other unsaved Work edits. Remove deleted Gallery IDs from loaded saved memberships and drafts; rename and delete refresh list labels. Bulk membership replacement remains the existing intersection/replacement contract.

## Deliverables

- Work editor field actions and shared definition modal presentation, with focused Gallery/Series service adapters.
- Canonical Gallery create/save/delete service operations with exact identity, definition revision and deletion member-set checks; reuse the existing transaction and output-completion owners.
- Updated [Work editor](d-20260422-000000-45a776.md) and [Catalogue completion](d-20260519-202931-0c703e.md) documentation.

## Process

1. Click New beside a field, enter a title and click OK. The definition is saved; a new Gallery is added to the displayed draft set. A new Series is selected in a single/New Work draft; bulk Series assignment remains unavailable.
2. Save the Work or selected Works to persist the assignment under existing Save semantics.
3. Click a Gallery pill's title or Series Edit to edit that exact shared definition. OK completes the title change and affected output independently of the Work draft.
4. Click Delete in Edit to review the confirmation. Confirming Gallery deletion removes it from every associated Work, including unselected Works. Cancelling discards the modal operation. An empty Series can be deleted through the same interaction.

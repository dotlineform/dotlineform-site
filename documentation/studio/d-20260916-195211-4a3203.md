# Catalogue Tokens From Document Subject

## Requirements

Add an optional Use document subject checkbox to Add Catalogue image and Add Media View link. Selecting it displays the document's exact Catalogue identity in the existing modal and inserts a token without that identity. Document Build resolves the identity from the source front matter. Authored labels and image presentation remain literal source.

Add Catalogue image enables the checkbox only for a Work subject from `work_id`; otherwise it is disabled and manual selection remains available. Add Media View link supports Work, Series and Detail subjects. This delivery adds no speculative subject-error handling or validation workflows. The user approved implementation and this narrowed validation boundary on 2026-09-16.

## Deliverables

- Shared modal checkbox, exact subject selection and abbreviated token serialization.
- Source editor subject context, Python and JavaScript token parsing, Build resolution, token Info editing and existing audit resolution.
- Current behavior documented in [Semantic Tokens Architecture](d-20260714-234030-434069.md).

## Process

Open either authoring modal, select Use document subject, retain or edit the label/image presentation, and insert. Media links follow the exact subject, including its Detail when applicable. Images may retain an explicitly selected `detail_id` under the subject Work. Save/Build resolves the identity into generated HTML and existing usage records while preserving abbreviated Markdown. Existing public media readers consume the resolved identity.

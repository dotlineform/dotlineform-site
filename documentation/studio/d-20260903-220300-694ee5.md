# Doc Navigation

This features improves how the user navigates from one document to another. Currently the index panel is the only means of selecting a document. This feature will introduce two new aspects to document navigation:

- the ability to move forwards or backwards through the index tree using prev/next controls
- the ability to reorder sibling documents in any order using drag and drop in the index panel.

These two combine to enable a more 'book like' reading experience for Analysis scope.

This feature applies to the scope-level document hierarchy and is independent of both [Unified Analysis And Catalogue Presentation](/docs/?scope=studio&doc=d-20260902-102745-8379ea) and [Catalogue Navigation](/docs/?scope=studio&doc=d-20260903-222617-28475e). It neither supplies Catalogue sub-scope/detail sequences nor needs the migration before it can be delivered.

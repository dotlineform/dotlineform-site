# Project State

## Purpose

Project State is the derived, read-only relationship model between Project documents, current folders, and the Series evidenced by historical Work source paths. It makes gaps and disagreement visible without turning any input into a canonical folder registry or granting mutation authority across systems.

The feature owns a persistent generated Docs Viewer document and the folder-keyed lookup consumed by downstream Resolver Tokens.

## Core Relationship

```text
Project documents[] <- folder_path -> Series[]
```

Folders are the row identity. Works are evidence used to derive the Series association; individual Works are not Project State report or resolver results.

## Current Data Shape

The 2026-08-02 planning snapshot contains 1,940 Works, all with at least one `series_id`. Their normalized folder evidence produces 145 folder rows: 143 folders relate to one Series and two relate to two Series. The current Projects Manage manifest contains 241 documents, of which 229 declare `folder_path`; 16 folder paths are shared by multiple documents and the largest group contains 14 documents.

These values justify arrays on both sides of a folder row, but they are current evidence rather than schema limits or permanent invariants.

## Delivery Relationship

PRJ-3 establishes the Project State model and saved report without deleting the current image-audit workflow. PMA-1 then preserves that audit under its accurate name and owns retirement of the old Studio route, generator placement, opener, activity contract, and static Markdown path. PRJ-4 may begin once PRJ-3's lookup, generation, freshness, and access contracts work independently; it does not depend on PMA-1.

## Boundary

Project State does not audit individual project images, enumerate Works as results, infer folders from titles, repair inputs, watch the filesystem continuously, or publish local relationships to public routes. [Projects](/docs/?scope=studio&doc=d-20260801-095819-30103c) owns the wider feature sequence and authority boundaries.

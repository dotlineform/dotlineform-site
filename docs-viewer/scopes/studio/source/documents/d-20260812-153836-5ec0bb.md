# EMW-1 — External Media Workspace And Public Projection Delivery

## Status And Purpose

This delivery is **complete and closed**. The external managed-media contract is active, explicit Publish independently reconciles referenced public media through the existing repository and R2 adapters, and the user accepted the Manage/public plus unpublish/republish cycle. [The temporary checkpoint record](/docs/?scope=studio&doc=d-20260812-164353-9e3115) retains the earlier inventory and counts-only cutover pending its explicit retirement decision.

## Complete Outcome

Every configured Docs Viewer parent scope stores managed media and registered media build sources in one external, scope-namespaced workspace. Repository and external-local document scope containers retain document and document/search roles but no media bytes. Add, Import, Manage, inventory, build relationships, Copy, and source evidence use the external workspace. Public-scope Publish derives the referenced media set from all publishable documents, projects it to the configured `site/` or R2 target with public URLs, and removes only stale public projections. Logical Markdown references do not change.

# notes on default report

tags report is already close to the default.

- the group filters and corresponding manifest `group` field are a customisation
- it currently lacks the default ability to sort the list in manage mode, and a 'copy link' button on a doc page

## report toolbar

all scopes (public + manage):

- search by title

manage only:

- New doc 📄
- sort toggle button:
    - 🔤 = `title` asc
    - 🕒 = `last_updated` desc
- Actions menu 🔧
    - Prepare package 📦
- checkbox controls (Select all, clear, done)

## list

- list of doc titles
- sorting is manage only
- additional columns are customisations

## doc toolbar

all scopes (public + manage):

- ← back

manage only:

- 🗑️ delete doc
- 'Copy Link' button

## manifest

public:

```
{
  "docs": [
    {
        "doc_id": "d-*",
        "title": "title"
    },
```

manage:

```
{
  "docs": [
    {
        "doc_id": "d-*",
        "title": "title"
        "ui_status": "",
        "viewable": true,
        "last_updated": ""
    },
```

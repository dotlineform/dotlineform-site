# Project State Report

## Retired

`studio/services/catalogue/project_state_report.py` and its `var/studio/reports/project-state.md` output were removed by [SSP-6.3](/docs/?scope=studio&doc=d-20260807-184959-09e16f). There is no compatibility command or replacement generated Markdown file.

Run **Uncataloged Files** and **Missing Source Files** from their separate local Docs Viewer report hosts. The shared source-image extension policy that had been imported from the old generator now belongs to `studio/services/catalogue/catalogue_media_files.py`.

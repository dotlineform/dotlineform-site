# Docs Viewer Roadmap

1. [Scope Media Management](/docs/?scope=studio&doc=d-20260720-100017-9855dd) - expose and extend provider-independent inventory and lifecycle understanding for media already owned by each scope

1. [Docs Viewer Core Refactor](/docs/?scope=studio&doc=d-20260718-114645-7b9d24) - extract an explicit core, make configuration and runtime dependencies composition-owned, and recompose the integrated application without changing product behavior

1. [Standalone Docs Viewer](/docs/?scope=studio&doc=d-20260511-120352-90ffa6) - package and release a self-contained external-local application as the first independent core consumer

1. [Share Sub-Scope Documents](/docs/?scope=studio&doc=d-20260720-173806-5f2c9a) - share a configured sub-scope as a document corpus without recreating domain adapters or canonical-data apply paths

1. [Public Docs Viewer Mobile Experience](/docs/?scope=studio&doc=d-20260723-191039-f8cb88) - review and deliberately redesign public scope, index, navigation, and reading behaviour for actual mobile browsers

1. [Semantic Reference Authoring](/docs/?scope=studio&doc=d-20260527-105208-c1a4d0) - improve semantic-reference authoring when a bounded need becomes important

1. [Dated Export Snapshots](/docs/?scope=studio&doc=d-20260716-193410-98d1a8) - retain small browseable snapshots outside Docs Viewer without creating an archive scope

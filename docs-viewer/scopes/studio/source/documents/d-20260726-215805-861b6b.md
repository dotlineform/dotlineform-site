# Offline Tag Assignment Session Removal Delivery

## Current State

- [x] Confirm the live browser, service/API, configuration/activity, and test
  consumers of the offline assignment contract.
- [x] Confirm the intended Studio browser profile has no offline assignment
  session to preserve.
- [x] Remove the contract, prove direct-save and failure behavior, and update
  durable documentation.

## Complete Result

Series Tag Editor saves assignments only through the direct Local Studio API.
Series Tags shows canonical coverage without offline overlays, Session or
Import controls, or reconciliation state.

No executable browser or server path reads, writes, exports, imports, previews,
applies, or clears the `tag_assignments_offline_v1` session.

## Data Disposition Gate

Before implementation, inspect the intended Studio browser profile for
`dotlineform.studio.tagAssignmentsOffline.v1`.

If it contains needed work, export or reconcile that work before removal. The
delivery does not migrate browser-local data into canonical assignments and
does not retain runtime cleanup or compatibility code merely to erase an inert
key. Any stale key left in a browser profile is outside the shipped application
contract after removal.

## In Scope

- Remove offline-session storage, normalization, clone/update helpers, copy,
  download, clear, and imported-entry cleanup.
- Remove Series Tag Editor save-mode switching, staged-row gating, offline base
  snapshots, offline status copy, and dynamic offline workflow loading.
- Keep failed direct-save edits in the current editor state with a clear
  service-unavailable or save-failed result.
- Remove Series Tags Session and Import controls, modal hosts, lazy modules,
  session/import route modes, staged overlays, conflict controls, and related
  text/styles.
- Remove assignment-session import preview/apply routes, dispatch, capabilities,
  runtime service keys, handlers, validation/planning, and activity actions.
- Remove offline/import-only tests and refocus remaining tests on direct save,
  canonical coverage, route boot, and unavailable-service behavior.
- Update durable documentation and current route/service inventories.

## Not In Scope

- Changing canonical assignment schema, values, inheritance, normalization, or
  atomic write ownership.
- Changing Series Tags coverage scoring, filters, sorting, or editor links.
- Changing tag registry, aliases, groups, promotion/demotion, or catalogue
  membership.
- Registry and alias bulk-import retirement, which remains owned by
  [Tag Vocabulary Import Retirement](/docs/?scope=studio&doc=d-20260726-214250-28ae69).
- A replacement offline queue, automatic retry, sync service, patch workflow,
  or browser-storage cleanup shim.

# Semantic Tokens

This manage-only, read-only report lists resolved semantic-token occurrences
from the selected Docs Viewer scope's generated usage index.

The three sortable columns are Title, Identity, and Document. Document links to
the managed document containing the occurrence. Unresolved or unusable
occurrences are absent from the usage index and remain the responsibility of
[Docs Broken Links](/docs/?scope=studio&doc=d-20260423-165116-e7f7e9).

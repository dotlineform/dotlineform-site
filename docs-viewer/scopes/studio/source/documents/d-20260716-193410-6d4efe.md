# Copy And Move Documents Between Scopes

## Shipped Contract

[Copy And Move Documents Between Scopes Delivery](/docs/?scope=studio&doc=d-20260723-223400-c7a1e4) delivered one independent Index **🛠️** menu containing **Copy to scope…** and **Move to scope…**, while leaving the existing **Select** lifecycle unchanged:

- Copy uses exact checked documents by default and offers optional descendants.
- Move forces descendants for every checked parent, preserves document identities, and removes sources only after the target succeeds.
- Both deduplicate overlapping parent/child selections and place effective roots at the target scope root.
- Both transfer the effective documents' referenced source-scope media through the configured provider boundary. Copy retains all source media; Move removes only transferred media no longer referenced by documents left in the source.
- Inline Mermaid remains unchanged canonical document source for both local and external-local targets; existing referenced Mermaid-backed media transfers with its registered source and published SVG.
- Preview is write-free. Apply revalidates the bounded document/media receipt, never overwrites a target identity, and reports exact observed state if follow-through fails.
- Public scopes may be Copy sources but are never targets. Move requires writable non-public source and target scopes.

The singular Copy control, browser workflow, service modules, and endpoints are retired without aliases. The earlier one-root, document-only delivery remains linked below only as implementation history; it is not a current product or code contract.

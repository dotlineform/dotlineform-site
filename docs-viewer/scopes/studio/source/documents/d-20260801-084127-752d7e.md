# Sub-Scopes

A sub-scope is a collection of normal Docs Viewer documents saved in a sub-folder of the main scope. These docs do not appear in the Index panel, instead they are listed in a Docs Viewer report page.

The benefit of a sub-scope collection is that hundreds of documents can be contained in a single sub-scope without overloading the main document Index-tree.

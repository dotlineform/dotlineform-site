# Studio Project State

## Retired

The former `/studio/project-state/` image-audit route and `var/studio/reports/project-state.md` output were retired by [SSP-6.3](/docs/?scope=studio&doc=d-20260807-184959-09e16f). The route, report/open APIs, activity action, frontend, generator, and static Markdown output no longer exist.

Use the local **Uncataloged Files** report for ordinary files in represented Work source folders that are not canonical Work primary sources. Use **Missing Source Files** for canonical Works whose complete expected source path does not resolve to a file. These reports show only their specified rows and do not reproduce the old workflow's counts or extra audit sections.

The local Docs Viewer **Project State** report is a different product. It reconciles real folders, Project documents, Works, and Series and was not retired by SSP-6.

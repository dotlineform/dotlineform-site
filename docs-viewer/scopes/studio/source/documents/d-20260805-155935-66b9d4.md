## Report Behavior

Each Folder cell removes the producer label's leading slash and displays only the first-level folder name while retaining the exact `projects/<folder>` identity and encoded local-target activation. Series links combine the producer's exact catalogue routes with the configured site-preview base and display only the Series name. Project-document links retain their exact scope, sub-scope, `doc_id`, and Manage URL. The browser does not display reconciliation-state labels, Series Work counts, incomplete-membership messages, or issue counts; absent Series or Docs values render as blank cells while that evidence remains in the accepted response.

A run disables the pill-shaped `🔄` control, exposes its `Run/Refresh` accessible name and busy state, updates the status line, and clears the prior rows. A successful response must carry matching report and lookup schema/generation identities before rows render. The completed status starts with the minute-precision GMT generation time and omits a label. An empty response renders a contained no-folders state. A failed request or invalid response retains no prior rows and renders one contained current-run error; the producer's accepted SSP-2.1 failure path retains the prior complete lookup and marks it stale.

The standalone Analytics application, source tree, runner, routes, APIs,
configuration, checks, and tests are retired.

- [Studio](/docs/?scope=studio&doc=d-20260423-000000-d015e6) owns
  canonical tags, tag services, and all five retained tag workflows.

  integrated document packages.

copy, or generic Data Sharing framework.

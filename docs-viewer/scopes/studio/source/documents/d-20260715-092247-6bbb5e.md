# Search Mechanics

Refine index inclusion, ranking, result context, and efficiency while retaining the current separate Catalogue and Docs Viewer static-search structure.

## Feature Documents

- [DSI-1 — Docs Viewer Search Index v2 Delivery](/docs/?scope=studio&doc=d-20260813-171341-8bfa80) — complete and closed; every Docs Viewer scope uses one inverted-index structure and one browser query path.
- [DSI-2 — Scope-Level Sub-Scope Search Delivery](/docs/?scope=studio&doc=d-20260813-225547-cd82d8) — proposed; include eligible documents from visibly hosted sub-scopes in one scope-level index with exact collection navigation and compact context.
- [SM-1 — Studio Full-Text Search Delivery](/docs/?scope=studio&doc=d-20260715-084611-c2fa6f) — complete and closed; Studio searches authored headings, prose, and code while structural identity, update, and parent context remain non-searchable.
- [SM-2 — Docs Viewer Search Relevance Delivery](/docs/?scope=studio&doc=d-20260813-222008-35fcfa) — proposed; establish one bounded corpus-adaptive relevance policy for Docs Viewer full-text scopes, using Studio first and Analysis when its public corpus is ready.
- [Studio Full-Text Search Index Concept](/docs/?scope=studio&doc=d-20260813-161942-b1e9e1) — retained design and prototype record.
- [Docs Viewer Search Tokenizer Concept](/docs/?scope=studio&doc=d-20260813-163802-5ca41f) — retained term-semantics proposal and reasoning.
- [Search](/docs/?scope=studio&doc=d-20260331-000000-5dcf32) — current architecture and known weak spots.

[Studio Documentation Maintenance](/docs/?scope=studio&doc=d-20260813-114338-c6b682) rationalised the Studio corpus and added exact same-scope backlink visibility before search delivery. DSI-1 and SM-1 are complete. Their Roadmap concepts and deliveries remain here, while current contracts and durable proposals belong to [Docs Viewer Search](/docs/?scope=studio&doc=d-20260602-160839-6d3cbb), [Docs Viewer Search Index](/docs/?scope=studio&doc=d-20260813-214350-4c7a21), [Docs Viewer Search Tokenizer](/docs/?scope=studio&doc=d-20260813-214351-98d3f0), and [Docs Viewer Search Relevance](/docs/?scope=studio&doc=d-20260813-223337-e6c261) outside the Roadmap hierarchy. Catalogue Search remains a separate later mechanics delivery.

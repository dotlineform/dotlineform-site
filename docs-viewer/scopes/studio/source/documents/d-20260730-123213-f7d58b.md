contracts and status.

## Delivery Order

```text
SSO-1 ordinary sub-scope Import
  -> SRR-2 returned-package sub-scope Import
  -> ERS-1 shared Build + edited review-source-folder Import
```

## Dispatch Rule

In integrated Import, registered collection recognizers receive the untouched
staged candidate and front matter first. Only an unclaimed ordinary Markdown
file or one-document Markdown package reaches generic front-matter stripping
and create-only Import.

This prevents ordinary normalization from erasing `review_*` provenance before
the edited-review-source recognizer can validate it.

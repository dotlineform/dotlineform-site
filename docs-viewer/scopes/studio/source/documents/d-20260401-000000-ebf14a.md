# Catalogue Works

## Live Report

[Open the Catalogue Works report](/docs/?scope=dotlineform&doc=d-20260810-222148-99daec). It sits with the other local `dotlineform` reports; this Studio page remains the durable ownership and extension guide.

The Studio home **works** entry resolves this target through `app.runtime.sites.docs_viewer.base`. The server uses `DOCS_VIEWER_BASE_URL` when supplied and otherwise constructs the Docs Viewer origin from `DOCS_VIEWER_HOST` and `DOCS_VIEWER_PORT`, so the link opens the Docs Viewer service instead of inheriting Studio's port.

The report loads every canonical Work with `status: published` but shows rows only after a Work or Series search. Results retain exact Work identity, every Series membership, year, and curator-only storage context in one sortable semantic table. **Copy table** exports the current sorted result as TSV.

## Data And Ownership

The local report registry maps `catalogue_works` to its exact allowlisted loader, and `docs-viewer/runtime/js/reports/catalogue-works-report.js` reads the browser-safe Local Studio Catalogue API keys `catalogue_works` and `catalogue_series`. Canonical Work rows own `storage_location`; the report does not read the generated public Catalogue or a parallel storage payload.

The report module owns validation, published-only selection, search, sorting, exact public-preview links, table rendering, clipboard projection, and contained unavailable or invalid states. Editing remains in the [Catalogue Work Editor](/docs/?scope=studio&doc=d-20260422-000000-45a776) and [Catalogue Series Editor](/docs/?scope=studio&doc=d-20260422-000000-ec1a69). [Catalogue Drafts](/docs/?scope=studio&doc=d-20260418-000000-16bf7e) remains the recovery and maintenance route for unfinished records.

## Extension And Weak Spots

- Add a report column only when the accepted canonical local read owns its value and the table, sorting, and TSV projections can stay aligned.
- Add curator-only context through a Studio-owned read, never by expanding or treating public payloads as an application model.
- Keep the report search-required: empty search reveals no rows, and a failed current read never retains an older result.
- Keep `catalogue_works` local-only. Public report metadata, loaders, data, and CSS do not expose it.

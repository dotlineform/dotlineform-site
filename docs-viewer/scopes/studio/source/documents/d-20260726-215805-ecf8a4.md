# Offline Tag Assignment Session Retirement

## Result

Series Tag Editor has one persistence path: a direct, allowlisted Local Studio
save to canonical tag assignments.

The browser-stored offline session, its Session and Import controls, exported
session format, conflict reconciliation, and server preview/apply endpoints are
removed. Series Tags remains the read-only cross-series coverage view and link
to each Series Tag Editor.

## Why

Offline staging was designed as failure recovery when direct local writes were
less dependable. It was not adopted in practice and now adds a second save
mode, browser-local state, conflict policy, import APIs, and UI that do not fit
the repository's direct Studio workflow.

Keeping only direct save makes the persistence authority visible and avoids
stranding changes in a browser profile or exported session file.

## Boundary

- Preserve canonical `tag-assignments.json` data and the current direct
  series/work assignment save contract.
- When the local write service is unavailable or a save fails, keep the current
  unsaved editor state visible and report a contained failure; do not silently
  stage it elsewhere.
- Remove offline storage, export, clear, import, preview/apply, conflict
  resolution, staged-row presentation, and their configuration and tests as one
  contract.
- Do not add a replacement queue, sync layer, patch format, background retry, or
  compatibility reader.
- Do not change tag scoring, inheritance, weights, alias-assisted selection,
  catalogue membership, or the read-only Series Tags table.
- Bulk registry and alias imports are owned separately by
  [Tag Vocabulary Import Retirement](/docs/?scope=studio&doc=d-20260726-214250-28ae69).

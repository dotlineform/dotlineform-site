# CWR-1 — Catalogue Works Report Migration Delivery

## Status And Purpose

CWR-1 is complete and closed. It delivered the core [Catalogue Works Report Migration](/docs/?scope=studio&doc=d-20260810-181816-dc9891): replace `/studio/studio-works/` with one local `catalogue_works` report hosted beside the other external-local `dotlineform` reports while the Studio Catalogue Works page remains durable documentation.

[RB-1 — Report Blocks Cutover Delivery](/docs/?scope=studio&doc=d-20260810-182610-c274f0) is complete, so the report can use the shipped block source, payload, and exact-host runtime. Optional data-backed filters and Expanded Report View remain later, separately approved work.

## Complete Outcome

- The report population is every exact canonical Work with `status: published`, read through accepted Local Studio Catalogue authority.
- An empty search renders no rows. A non-empty search matches normalized Work id, title, and exact Series id or title.
- Results use one semantic table with **Work**, **Year**, **Title**, **Series**, and **Storage** columns, retain every exact Series membership, and support accessible column sorting.
- Exact Work and Series links retain their existing targets. **Copy table** emits the complete current sorted result with headers as tab-separated text.
- [Catalogue Works](/docs/?scope=dotlineform&doc=d-20260810-222148-99daec) is the exact live host beside the other `dotlineform` reports; the [Studio Catalogue Works page](/docs/?scope=studio&doc=d-20260401-000000-ebf14a) documents the report and owns no Report Block.
- `/studio/studio-works/`, its dedicated frontend owners, configuration, checks, smoke, text, CSS, and exact inbound navigation are removed in the same cutover with no redirect or duplicate reader.
- Catalogue Drafts and focused Work and Series editors remain unchanged. No public report capability, report-specific server product, optional filter, or expanded presentation is added.

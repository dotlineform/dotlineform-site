# Mermaid Authoring And Publication

## Purpose

Make an accessible fenced Mermaid block the preferred source for a diagram that belongs to one document. Managed local readers render that source in memory using the active Docs Viewer theme; public publication materializes validated light and dark SVG derivatives without shipping Mermaid to public browsers.

## Feature Documents

- [Public Mermaid Projection Delivery](/docs/?scope=studio&doc=d-20260724-190603-0d87a0) — dual static public variants, projection-owned lifecycle, theme selection, and detail links.

## Feature Contract

- Canonical document-contained Mermaid remains inside Markdown as one accessible fenced block.
- Managed `local` and `local_external` readers render that source in memory and create no persistent media.
- Public projection renders the same source into light and dark sanitized SVG derivatives and serves no Mermaid runtime or source.
- Source-faithful Markdown and static HTML exports continue to retain the fence until a reader-oriented export defines a separate need.
- A canonical `.mmd` plus published SVG remains appropriate when a diagram is reusable, independently addressable, downloadable, or explicitly managed as scope media.
- Finished authored SVG remains ordinary persistent media and does not become theme-sensitive automatically.
- Generated public variants are projection-owned output. They are not canonical `.mmd` media, Markdown tokens, or independently edited files.
- Existing inline and persistent diagram surfaces retain their accessibility, responsive sizing, horizontal-scroll, and Diagram Detail View contracts.

## Shipped Outcome

The feature is complete. Public preparation builds a manifest-owned light/dark pair before the existing publish gate runs; that gate revalidates and projects only complete current pairs. The public reader then selects the active variant and keeps its single image and detail target aligned with public-site theme changes. [Document Diagrams](/docs/?scope=studio&doc=d-20260719-123719-fb7565) owns the authoring, preparation, publication, and code-authority guidance.

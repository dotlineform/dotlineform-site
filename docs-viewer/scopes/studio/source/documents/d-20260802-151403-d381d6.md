# TE-4 — Managed Table Tools Delivery

## Status And Purpose

Proposed as **TE-4**, after [TE-3](/docs/?scope=studio&doc=d-20260802-150247-b5dffe) proves the public-safe `content-detail` main view and lightweight static Markdown table presentation in public and Manage readers.

TE-4 adds table tools only through the Manage composition. It extends the same registered view, main-panel layout, exact table target, semantic table renderer, and `main-view` toolbar. It does not create a managed table viewer beside the public one.

## Complete Outcome

When the active Content Detail target is a Markdown table on a Manage route, the table supports pointer and keyboard-accessible column resizing with session-local **Reset widths**. The existing main-view toolbar also offers **Copy as CSV**.

The public table view remains the static TE-3 presentation. No source, table identity, column widths, or exported file is persisted. Copy reads only the accepted semantic table presentation and emits no successful-action status message.

## Current Seams And Scope Guard

The likely blast radius is the Manage contribution boundary for the shared table adapter, session-local resize state and CSS, main-view controls, a pure CSV serializer, and clipboard invocation. The public TE-3 composition remains static.

If implementation requires a second view, renderer fork, source parser, stable table registry, persisted widths, or a public dependency on Manage code, stop for review and split the result.

## Rough Delivery Steps

### TE-4.0 — Confirm Scope And Delivery

- [ ] Sanity-check resizing, Reset, CSV serialization, and clipboard behavior against the shipped TE-3 table target and Manage contribution model; resolve only contradictions that would change the outcome.
- [ ] Confirm the broad blast radius across Manage table contributions, transient geometry, toolbar controls, serializer, clipboard, and the public import boundary.
- [ ] Confirm the deliverables: accessible session-local resizing and Reset, deterministic Copy as CSV, focused evidence for both, and concise durable extension guidance.
- [ ] Stop for review if the result crosses the scope guard above. Do not produce an exact file inventory, line estimate, frozen implementation, fixture implementation, or complete test architecture at this gate.

**Checkpoint:** a concise sanity note confirms the spec, broad owners, deliverables, and stop condition. Stop before implementation approval.

### TE-4.1 — Add Resizable Columns

- [ ] Contribute Manage-only table capability to the active shared table target without changing public target or renderer identity.
- [ ] Add accessible component resize handles to eligible header boundaries.
- [ ] Recompute the table and sticky first-column geometry through the focused table adapter only.
- [ ] Add **Reset widths** to the existing main-view toolbar and restore the TE-3 natural-width presentation for the active session.
- [ ] Release all resize listeners and transient widths on Back, navigation, target replacement, or view disposal.

### TE-4.2 — Add Copy As CSV

- [ ] Implement the specified pure semantic-table-to-CSV serializer independently of Markdown source and report models.
- [ ] Add **Copy as CSV** to the existing main-view toolbar only for eligible Manage table targets.
- [ ] Request clipboard access only from the explicit action, emit no success message, and project failure through the existing error surface.
- [ ] Preserve ordinary table selection, links, resizing, sticky geometry, and Back behavior after copy succeeds or fails.

### TE-4.3 — Verify And Transfer

- [ ] Run focused pure serializer and resize/control lifecycle checks, plus the public import-boundary check if composition changed.
- [ ] Manually review pointer and keyboard resizing, Reset, and CSV copy with one representative table at supported desktop widths, including Back or navigation cleanup.
- [ ] Update only the durable Content Detail/table or toolbar owner whose Manage extension contract changed.

## Not In Scope

- a second table view or Manage-specific table renderer;
- Download CSV, other export formats, file pickers, or server-side export;
- public promotion of resizing or Copy as CSV;
- persisted widths, stable table IDs, saved presets, or cross-session settings;
- freezing more than the first column or user-selected frozen columns;
- sorting, filtering, grouping, row selection/actions, editing, formulas, charts, or virtualization;
- parsing Markdown source to recover links or formatting; or
- diagram presentation, which belongs to TE-5.

The [Table Enhancements feature](/docs/?scope=studio&doc=d-20260802-150245-4e7f85) owns sequencing. [Content Detail View Concept And Architecture](/docs/?scope=studio&doc=d-20260802-150246-bb3f88) owns the shared view and static-source boundaries.

# Series Tags

## Capability

`/studio/series-tags/` is the cross-series assignment review. It shows
canonical coverage/status and links into the one-series editor.

The page does not directly edit table rows. Editing happens in
[Series Tag Editor](/docs/?scope=studio&doc=d-20260331-000000-643429).

## Data Path

```text
public series index
  + canonical assignments
  + registry/group config
  -> coverage/status table
  -> selected series editor link
```

Coverage scoring is implemented by `analysis-tag-scoring.js` using
`analysis.groups` and `analysis.rag` projected from Studio tag policy.
Assignments carry flat tag IDs. The report resolves each tag's group, label,
filtering, and chip styling from the registry; it never derives group from the
ID.

## Code Map

- template/controller: `series-tags.html`, `series-tags.js`
- report/table: `series-tags-render.js`, `analysis-tag-scoring.js`

The route uses Studio ready/busy state and remains in list mode.

## Weak Spots

- Coverage status combines canonical assignment data with generated catalogue indexes; either side can be stale.

# Studio Mermaid SVG-To-Inline Theme Migration

## Status And Purpose

This completed standalone delivery moved the existing Studio diagrams that used Mermaid-built persistent SVG media to Studio's theme-aware inline Mermaid default. As one bounded migration, this direct [Roadmap](/docs/?scope=studio&doc=d-20260428-000000-f5ff18) child owns both the small feature snapshot and its delivery.

The five diagrams had canonical accessible `.mmd` source that delegated colour selection to Mermaid's theme defaults. Their fixed-light SVG presentation predated the managed inline renderer; their canonical document fences now let the established Studio theme owner render them in the active light or dark theme.

## Complete Outcome

The five named diagrams use accessible fenced Mermaid as canonical content in their existing Studio documents. They render through the current managed inline adapter, follow the active Studio theme, and retain the existing Diagram Detail and **Open in new tab** behavior.

Embedded or persistent SVG media remains a supported authoring option for finished vectors, independently reusable diagram media, non-Mermaid SVG, and imported local documents. Any later conversion of embedded SVG in imported local documents is a separate delivery with its own selected inventory and source-availability decisions. Public scopes retain their current source, build, publication, theme-pair, and runtime contracts.

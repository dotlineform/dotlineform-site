# Analytics Retirement Overview

## Final State

The standalone Analytics application was retired after its durable
responsibilities reached their final owners:

- Studio owns canonical tags, aliases, groups, assignments, tag policy,
  services, APIs, transactions, activity integration, and retained browser
  workflows.
- Integrated Docs Viewer owns document-package preparation, return, review, and
  import.
- Tag-package sharing and the generic Data Sharing framework remain retired.

There is no Analytics runtime, configuration, server, runner, route registry,
API namespace, or test/check family.

The public `/analysis/` scope is a Docs Viewer knowledge surface. Its route
name does not preserve or imply the former application.

## Maintenance Rule

New tag work belongs to Studio. New document-package work belongs to integrated
Docs Viewer. A concrete future visualisation or report belongs with the domain
that owns its source and workflow; it is not a reason to recreate a generic
Analytics app.

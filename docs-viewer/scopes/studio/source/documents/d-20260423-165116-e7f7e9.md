# Docs Broken Links

This is a Docs Viewer management report for a read-only docs audit, not a public hosted feature. The report lists missing target links:

- links inside rendered code blocks are ignored
- same-doc fragment links are ignored, this includes `#section` and links back to the current docs page with a fragment

The same read-only audit scans semantic-token source independently of resolved usage. Catalogue diagnosis covers unsupported kinds, missing targets/destinations, and image/detail failures. Tag diagnosis distinguishes an unknown canonical Tag, zero current document associations, and an unusable exact selected-primary-or-first destination; a stale primary that resolves through the first current association is not broken. The report never mutates source, Tag Registry, or document declarations.

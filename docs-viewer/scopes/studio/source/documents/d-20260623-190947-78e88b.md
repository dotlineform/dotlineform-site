# Shareable Content Blocks Concept (Retired)

This proposal depended on the former Analytics/Data Sharing ownership model and
was retired without implementation.

Current boundaries are narrower:

- integrated Docs Viewer owns supported document packages;
- Studio owns canonical tags and manual tag writes;
- optional LLM-assisted tag development is advisory and human-mediated;
- Semantic Tokens remain deterministic Docs Viewer authoring/rendering work,
  not a returned-content workflow.

Do not use this concept as architecture or implementation guidance.

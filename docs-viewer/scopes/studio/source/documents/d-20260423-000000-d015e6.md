# Studio

Studio is the local catalogue authoring and maintenance app. [Studio Overview](/docs/?scope=studio&doc=d-20260715-084611-ae9636) gives the short capability, execution, authority, extension, and weak-spot model.

## Use Studio

- [Catalogue Works](/docs/?scope=studio&doc=d-20260401-000000-ebf14a) — browse and open works.
- [Catalogue Work Editor](/docs/?scope=studio&doc=d-20260422-000000-45a776) — create and edit works and their detail sections.
- [Catalogue Series Editor](/docs/?scope=studio&doc=d-20260422-000000-ec1a69) — create and edit series and membership.
- [Catalogue Drafts](/docs/?scope=studio&doc=d-20260418-000000-16bf7e) — find incomplete and draft records.
- [Bulk Add Work](/docs/?scope=studio&doc=d-20260419-000000-cb98dd) — preview and apply workbook imports.
- [Catalogue Field Registry](/docs/?scope=studio&doc=d-20260501-172902-96e85d) — review field definitions and build participation.
- [Tag Source Data](/docs/?scope=studio&doc=d-20260419-000000-86255c) — canonical tag data, services, and the five tag-management workflows.
- [Series Tags](/docs/?scope=studio&doc=d-20260331-000000-974bf0) — review coverage and reconcile staged assignment sessions.
- [Series Tag Editor](/docs/?scope=studio&doc=d-20260331-000000-643429) — edit one Series and its Work overrides.

## Code Authority

Verify exact current behavior in:

- `studio/app/frontend/config/` and `studio/app/server/studio/studio_app_config.py` for route and runtime configuration
- `studio/app/frontend/` for the shell, templates, route scripts, and shared browser helpers
- `studio/app/server/studio/` for local HTTP routing plus catalogue and tag API adaptation
- `studio/services/catalogue/` and `studio/services/tags/` for domain behavior and write authority
- `studio/data/config/`, `studio/data/canonical/`, and `studio/data/generated/` for config and data ownership
- `studio/tests/python/` for focused deterministic evidence
- `studio/tests/smoke/` for the three retained route-integration boundaries

Use code/config search for exact fields, routes, endpoints, or modules. Copying them into this page would make the entry point harder to trust.

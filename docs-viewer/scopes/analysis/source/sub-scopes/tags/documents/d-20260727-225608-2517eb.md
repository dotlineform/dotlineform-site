# nerve

**domain**

Nerve as a discourse frame: bodily sensitivity, pain, transmission, vulnerability, shock, and the boundary between physical sensation and psychological disturbance. Use where the work invokes nervous-system language, exposed sensitivity, electric/impulsive feeling, trauma registered in the body, or the body as a conduit for affect.

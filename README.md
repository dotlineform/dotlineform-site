# dotlineform.com

This repository is the source for [dotlineform.com](https://www.dotlineform.com), deployed to GitHub Pages from the tracked static site root in `site/`.

The repo also contains locally run web apps:

- **Studio**: manage portfolio catalogue and tag data for the site.
- **Admin**: run local checks, audits, activity, and operational reports.
- **Docs Viewer**: manage and publish documents, including the *analysis* site page.
